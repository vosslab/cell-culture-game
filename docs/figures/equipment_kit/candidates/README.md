# Archived SVG candidate review fixtures

This tracked M5 tree preserves five rejected historical construction snapshots
for a generic T75 flask, compact benchtop centrifuge, P200 micropipette, and
15 mL conical tube. It is not application art, an equipment-kit contract, a
manifest input, or a regeneration target. The frozen SVGs and PNGs document
the rejected cubist/faceted direction only.

The former four-object [review page](review.html) redirects to the generated
canonical gallery at `docs/figures/equipment_kit/review.html`, produced by
`tools/render_svg_library_review.mjs`.
The obsolete candidate renderer and CSS are not part of the current workflow.
The retained PNGs are historical implementation evidence and are not a visual
test or a source of current art direction. Review the current library through
`docs/figures/equipment_kit/review.html`, generated by
`tools/render_svg_library_review.mjs`; inspect its source cards under `file://`
and use the live scene viewer for runtime scale and material behavior.

## Measured placement and frozen-source acceptance

The real-size and crop panels measure each SVG's browser-decoded alpha bounds
at render time. They crop and translate that review-only raster so the visible
alpha rectangle exactly occupies the M3 visual box. Several historical M3
width/height boxes differ from a candidate's alpha aspect ratio; those panels
therefore use independent X/Y raster scales. This is a literal scene-placement
diagnostic, not a production translation or a decision to distort canonical
SVG art. Enlarged bench panels instead preserve source geometry and align the
authored `anchor-baseline` coordinates on one shared bench line.

Before the render handoff, all frozen source fixtures passed the M0 shadow
screen. The exact acceptance command was run once for every table entry:

```bash
source source_me.sh && python3 -m tools.svg_normalizer.cli --shadow-dry-run -i <source.svg>
```
