This generated structural baseline covers every current equipment SVG in the manifest.

## Measurement method

- Layout comes from the real `runPipeline` result for every generated scene.
- Final boxes already include that scene's `reflowUniformScale`; the factor is retained per placement.
- Fractions are visual-box width divided by the 16:9 frame width.
- The smallest frame is emitted by `interactionGeometry.minimum_frame` and reserved by
  `.scene-panel-inner` CSS variables, so it is the smallest currently valid scrollable scene frame.
- Visible root clusters are an inventory signal, not a flatness, volume, or visual-quality verdict.
- A well-constructed SVG may deliberately use one root group.
- Explicit `<ellipse>` and rotate/skew transforms stay separate structural signals.
