# Third-party assets

The canonical per-file source mapping for retained equipment artwork is
[the equipment source ledger](../assets/equipment/SOURCES.md). Add a confirmed
external source to that ledger before reusing its artwork. Repository-authored
artwork is recorded by Git history and is outside this attribution inventory.

This page owns project-level license and credit requirements. It intentionally
does not duplicate the per-file table.
